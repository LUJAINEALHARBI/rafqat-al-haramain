# تطبيق رفقة بلاد الحرمين

واجهة الجوال لمشروع «رفقة بلاد الحرمين» مبنية بـ Flutter، ومتصلة بنفس قاعدة
البيانات التي يستخدمها الموقع.

## الملفات

- نقطة الدخول: `lib/main.dart`
- شاشة تسجيل الدخول: `lib/app/main.dart`
- لوحات المستخدمين: `pilgrim_dashboard.dart` ، `supervisor_dashboard.dart` ، `manager_dashboard.dart`
- **الاتصال بقاعدة البيانات: `lib/services/api_service.dart`**
- الشعار: `assets/images/logo.png` (نفس شعار الموقع)

## كيف يتصل التطبيق بقاعدة البيانات

التطبيق لا يتصل بـ MySQL مباشرة — يرسل طلباته إلى ملفات PHP في مجلد
`website/api/` وهي وحدها التي تفتح قاعدة البيانات، تماماً مثل الموقع.
بهذا تبقى بيانات الاتصال على الخادم ولا تصل للجوال إطلاقاً.

- تسجيل الدخول: `auth.php?action=login` — الخادم يتحقق من كلمة المرور
  بـ `password_verify` ويحدد الدور والقسم من قاعدة البيانات.
- ملف الحاج: `pilgrims.php?action=get`
- ملف المشرف ووظيفته: `supervisors.php?action=profile`
- بيانات الحملة: `campaign.php?action=get`

المسمى الوظيفي للمشرف صار يُقرأ من جدول `jobs` عبر `supervisors.job_id`،
بدل استنتاجه من آخر رقم في العضوية.

## الإعداد قبل التشغيل

افتحي `lib/services/api_service.dart` وعدّلي سطراً واحداً فقط:

```dart
static String baseUrl = 'http://10.0.2.2/website/api';
```

| الحالة | القيمة |
|---|---|
| محاكي أندرويد مع XAMPP على نفس الجهاز | `http://10.0.2.2/website/api` |
| جوال حقيقي على نفس الواي فاي | `http://192.168.1.5/website/api` (ضعي IP جهازك) |
| محاكي iOS على ماك | `http://localhost/website/api` |

ثم:

```
flutter pub get
flutter run
```

> **مهم:** الاستضافة المجانية InfinityFree تحجب أي طلب لا يأتي من متصفح
> (ترد بصفحة تحقق `aes.js` بدل البيانات)، فلا تصلح لتشغيل التطبيق.
> التطبيق يعمل مع XAMPP محلياً أو مع استضافة مدفوعة.

## الحسابات

أرقام العضوية تتبع نفس قاعدة الموقع وقاعدة البيانات:
`100xxx` حاج/حاجة، `500xxx` مشرف متخصص، `5000` المشرف العام، `300xxx` مدير الحملة.
