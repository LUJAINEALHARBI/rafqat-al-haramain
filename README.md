# رفقة بلاد الحرمين

نظام لإدارة حملة حج يخدم ثلاث فئات من المستخدمين: الحاج، المشرف المتخصص، ومدير الحملة.
يتيح للحاج متابعة بيانات سكنه ووجباته ونقله وتقييم الخدمات، ويتيح للمشرف متابعة الحجاج المسندين
إليه ومهامه ومصروفاته، ويتيح لمدير الحملة إدارة المشرفين والخدمات وإسناد الحجاج.

المشروع يتكوّن من جزئين: موقع إلكتروني متصل بقاعدة بيانات، وتطبيق جوال.

## التقنيات المستخدمة

- **الموقع:** HTML / CSS / JavaScript
- **الواجهة الخلفية:** PHP 8 (PDO واستعلامات مجهّزة وجلسات)
- **قاعدة البيانات:** MySQL / MariaDB — 13 جدولاً، `InnoDB` بترميز `utf8mb4_unicode_ci`
- **التطبيق:** Flutter / Dart
- **بيئة التشغيل المحلية:** XAMPP (Apache + MySQL)

## محتويات المستودع

```
rafqat-al-haramain/
├── website/      الموقع — يوضع داخل htdocs
│   ├── api/      ملفات PHP (تسجيل الدخول، الحجاج، المشرفين، الخدمات، المصروفات، المحادثة...)
│   ├── sql/      ملف قاعدة البيانات مع بيانات تجريبية
│   ├── css/      ملف التنسيق
│   ├── js/       سكربتات الواجهة
│   ├── images/   الشعار
│   └── *.html    صفحات الموقع
├── mobile_app/   تطبيق Flutter
│   ├── lib/      شاشات التطبيق ولوحات المستخدمين
│   ├── assets/   الشعار
│   └── android/  إعدادات بناء أندرويد
├── docs/         شرح_المشروع.md + مخطط ER
```

### مجلد الموقع — `website/`

هذا هو المجلد الذي يُنسخ داخل `htdocs`. الصفحات ثابتة (HTML) وتتواصل مع قاعدة البيانات
عبر ملفات PHP في `website/api/`، وملف قاعدة البيانات في `website/sql/`.

### مجلد تطبيق الجوال — `mobile_app/`

تطبيق Flutter بنفس شعار الموقع وبنفس نظام أرقام العضوية. نقطة الدخول `lib/main.dart`
وشاشة تسجيل الدخول في `lib/app/main.dart`. هذه النسخة واجهة عرض تعمل ببيانات تجريبية
داخل الشاشات وغير متصلة بقاعدة البيانات؛ الربط الفعلي موجود في الموقع.

## طريقة تشغيل المشروع

### الموقع

1. ثبّتي XAMPP وشغّلي **Apache** و **MySQL**.
2. انسخي مجلد `website` إلى `htdocs` (مثلاً `C:\xampp\htdocs\website`).
3. من phpMyAdmin أنشئي قاعدة بيانات باسم `rafqa_haramain` بترميز `utf8mb4_unicode_ci`،
   ثم استوردي الملف `website/sql/rafqa_haramain_final.sql`.
4. انسخي ملف الإعدادات:

   ```
   cp website/api/config.example.php website/api/config.php
   ```

   القيم الافتراضية تكفي على XAMPP (المستخدم `root` وكلمة المرور فارغة).
5. افتحي المتصفح على `http://localhost/website/index.html`.

> على استضافة حقيقية: اضبطي متغيرات البيئة الموجودة في `website/.env.example`
> واجعلي `debug` بقيمة `false` في `config.php`.

### التطبيق

```
cd mobile_app
flutter pub get
flutter run
```
