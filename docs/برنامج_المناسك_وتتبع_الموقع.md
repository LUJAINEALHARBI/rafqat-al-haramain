# برنامج المناسك وتتبع الموقع

هذان أهم ما أُضيف في هذه المرحلة. كلاهما يعمل على بيانات حقيقية في قاعدة البيانات،
لا على نصوص مكتوبة داخل الصفحات.

---

## أولاً: برنامج المناسك (تتبع رحلة الحاج)

### الفكرة

الحاج يحتاج أن يعرف رحلته كاملة: أين هو الآن، وما الذي انتهى منه، وما الذي بقي،
ومتى، وكيف ينتقل من مكان إلى آخر (حافلة؟ قطار المشاعر؟ سيراً؟).
والمشرف يحتاج أن ينشئ هذه الرحلة ويرتّبها ويعلّم ما أُنجز منها أولاً بأول.

### الجداول

**`journey_programs`** — برنامج الرحلة

| العمود | الوصف |
|---|---|
| `program_id` | المفتاح الأساسي |
| `campaign_id` | الحملة صاحبة البرنامج |
| `program_name` | اسم البرنامج، مثل «برنامج مناسك الحج» |
| `hijri_year` | السنة الهجرية |
| `section` | القسم المستهدف: رجال / نساء / القسمان |
| `is_active` | هل البرنامج منشور للحجاج |
| `created_by` | المشرف الذي أنشأه |

**`journey_stations`** — محطات الرحلة

| العمود | الوصف |
|---|---|
| `station_id` | المفتاح الأساسي |
| `program_id` | البرنامج التابعة له |
| `station_order` | ترتيب المحطة داخل الرحلة (فريد داخل البرنامج) |
| `station_name` | اسم المحطة، مثل «النفرة من عرفة إلى مزدلفة» |
| `place_name` | المكان، مرتبط بأسماء المواقع في `site_locations` |
| `hijri_day` | اليوم الهجري، مثل «9 ذو الحجة» |
| `start_datetime` / `end_datetime` | وقت بداية المحطة ونهايتها |
| `transport_type` | وسيلة الانتقال: لا يوجد / سيراً على القدم / حافلة / قطار المشاعر / سيارة |
| `latitude` / `longitude` | إحداثيات المحطة لفتحها على الخريطة |
| `status` | لم تبدأ / جارية / مكتملة |
| `completed_at` | وقت تعليم المحطة منجزة |
| `updated_by` | المشرف الذي حدّث الحالة |

الربط: `journey_stations.program_id → journey_programs.program_id` بحذف متتالٍ،
و`journey_programs.campaign_id → campaigns.campaign_id`.

### الشاشات

| الشاشة | لمن | ماذا تفعل |
|---|---|---|
| `schedule.html` | الحاج (وبقية الأدوار للعرض) | الرحلة كاملة: نسبة التقدم، المرحلة الحالية، وكل محطة بوقتها ووسيلتها وحالتها |
| `admin-journey.html` | من يملك `manage_journey` | إنشاء البرنامج، إضافة المحطات وتعديلها، تغيير ترتيبها، تعليم المنجز، حذف محطة |

### الـ API — `api/journey.php`

| العملية | الطريقة | من يستطيع |
|---|---|---|
| `program` | GET | كل مستخدم مسجّل (الحاج يرى برنامج قسمه) |
| `programs` | GET | المشرف ومدير الحملة |
| `add_program` | POST | `manage_journey` |
| `update_program` | POST | `manage_journey` |
| `add_station` | POST | `manage_journey` |
| `update_station` | POST | `manage_journey` |
| `set_status` | POST | `manage_journey` |
| `move_station` | POST | `manage_journey` |
| `delete_station` | POST | `manage_journey` |

نسبة التقدم تُحسب في الخادم: عدد المحطات المكتملة ÷ إجمالي المحطات، والمرحلة
الحالية هي أول محطة غير مكتملة.

### البيانات المُدخلة

البرنامج المرفق في `sql/update_v2.sql` فيه رحلة حج حقيقية من 14 محطة:
التجمع والانطلاق، الوصول والتسكين، الإحرام والتوجه لمنى يوم التروية، المبيت في منى،
الانتقال لعرفة، الوقوف، النفرة لمزدلفة، المبيت وجمع الحصى، الانتقال لمنى،
رمي جمرة العقبة والحلق والهدي، طواف الإفاضة والسعي، المبيت ورمي الجمرات،
النفرة من منى، ثم طواف الوداع. كل محطة بوقتها وإحداثياتها الحقيقية.

## ثانياً: تتبع الموقع

### الفكرة

الحاج قد ينفصل عن مجموعته في الحرم أو في المشاعر. فتُتاح له مشاركة موقعه بضغطة
واحدة، ويظهر للمشرف على الخريطة مع أقرب موقع من مواقع الحملة والمسافة إليه.
وفي الوقت نفسه، مواقع الفندق والمخيمات والمشاعر صارت تُقرأ من قاعدة البيانات
بدل أن تكون إحداثيات مكتوبة داخل صفحة الخريطة.

### الجداول

**`site_locations`** — مواقع الحملة

| العمود | الوصف |
|---|---|
| `site_id` | المفتاح الأساسي |
| `campaign_id` | الحملة |
| `site_name` | اسم الموقع (فريد داخل الحملة) |
| `site_type` | فندق / مخيم / مشعر / نقطة تجمع |
| `description`, `period_note` | وصف الموقع وفترة الإقامة فيه |
| `latitude`, `longitude` | الإحداثيات |
| `section` | رجال / نساء / القسمان |

**`pilgrim_locations`** — مواقع الحجاج

| العمود | الوصف |
|---|---|
| `location_id` | المفتاح الأساسي |
| `pilgrim_id` | الحاج (حذف متتالٍ مع الحاج) |
| `latitude`, `longitude` | الإحداثيات القادمة من المتصفح |
| `accuracy_m` | دقة التحديد بالأمتار |
| `recorded_at` | وقت المشاركة |

### الـ API — `api/location.php`

| العملية | الطريقة | من يستطيع |
|---|---|---|
| `sites` | GET | كل مستخدم مسجّل (كلٌّ يرى مواقع قسمه والمواقع العامة) |
| `report` | POST | الحاج فقط — يحفظ موقعه |
| `my_last` | GET | الحاج — آخر موقع شاركه |
| `pilgrims` | GET | `view_locations` — آخر موقع لكل حاج في النطاق |
| `history` | GET | `view_locations` — آخر 20 موقعاً لحاج معيّن |
| `add_site` / `delete_site` | POST | `manage_sites` |

أقرب موقع والمسافة يُحسبان داخل الاستعلام بصيغة **هافرساين**:

</div>

```sql
6371 * ACOS(
    COS(RADIANS(?)) * COS(RADIANS(latitude)) *
    COS(RADIANS(longitude) - RADIANS(?)) +
    SIN(RADIANS(?)) * SIN(RADIANS(latitude))
) AS distance_km
```

ومواقع قسم النساء لا تدخل في حساب أقرب موقع لحاج من قسم الرجال والعكس.

### الشاشة

صفحة واحدة `map.html` تتغيّر حسب المستخدم:

| المستخدم | ما يراه |
|---|---|
| الحاج | مواقع قسمه + زر «شارك موقعي» + آخر موقع شاركه وأقرب موقع إليه |
| مشرف يملك `view_locations` | المواقع + علامات الحجاج على الخريطة + جدول بآخر موقع لكل حاج ومتى شاركه |
| مشرف بلا هذه الصلاحية | المواقع فقط، مع سطر يوضّح أن متابعة الحجاج ليست من مهام وظيفته |
| مدير الحملة | كل ما سبق لكل أقسام الحملة |

وقت المشاركة يُحسب داخل قاعدة البيانات بـ `TIMESTAMPDIFF(MINUTE, recorded_at, NOW())`
حتى لا يختلف الحساب باختلاف توقيت الخادم عن توقيت PHP.

### ملاحظة عملية

لا توجد مواقع حجاج مُدخلة مسبقاً في ملف قاعدة البيانات، لأن الموقع بيانات حقيقية
تأتي من جوال الحاج. لتجربة الميزة: ادخلي بحساب حاج ← صفحة الخريطة ← «شارك موقعي»
واسمحي للمتصفح بالوصول للموقع، ثم ادخلي بحساب المشرف لترى الحاج على الخريطة.
